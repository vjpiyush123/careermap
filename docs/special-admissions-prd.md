# Special Admissions — Product Requirements Document

## 1. Overview

A dedicated page in CareerGuide that consolidates special/direct admission criteria across Indian colleges. Students can discover alternative admission routes beyond standard entrance exams, understand eligibility, and access verified official sources for each category.

## 2. Problem Statement

Many students are unaware of special admission quotas, direct-entry schemes, and reservation-based routes that could qualify them for seats in top institutions. Information is scattered across hundreds of college websites, government portals, and counselling bodies, making it difficult for 10th/12th students to discover and act on these opportunities in time.

## 3. Goals

- Consolidate all major special admission categories in one place
- Map each category to the types of institutions that accept it
- Provide verified, authoritative source links for each category
- List key certificates/documents students should collect early
- Enable filtering by admission category and institution type

## 4. Target Users

- Students in 10th–12th standard exploring admission options
- Parents/guardians planning their child's higher education
- School counsellors advising students on available routes

**Key Certificates:** PwD certificate (UDID), EWS certificate from tehsildar, single girl child affidavit

**Verified Sources:**

## 7. Key Documents Checklist

Students should proactively collect these documents before the admission cycle:

1. **Board marksheets** — 10th & 12th (original + attested copies)
2. **Category certificate** — SC/ST/OBC/EWS (from competent authority)
3. **Domicile certificate** — from district magistrate / tehsildar
4. **PwD certificate** — UDID card (if applicable)
5. **Income certificate** — for EWS / fee waiver eligibility
6. **Sports certificate** — SAI grading / federation certificate
7. **NCC certificate** — A/B/C certificate (original)
8. **Olympiad certificates** — HBCSE / stage-level proof
9. **Defence dependent card** — if applicable
10. **Migration certificate** — from previous board/university
11. **Passport-size photographs** — 20+ copies (recent)
12. **Aadhaar card** — for identity verification

## 8. Page Design

### 8.1 Layout

- **Page Header:** Title + subtitle explaining purpose
- **Category Cards:** One collapsible/expandable section per admission category (9 categories)
- Each card contains:
  - Category title with icon
  - Description
  - Eligibility criteria table (criterion, description, applicable institutions)
  - Key certificates needed
  - Verified source links (clickable, open in new tab)
- **Documents Checklist:** Summary section at the bottom with all key documents
- **Filter:** Dropdown to filter by institution type (IITs, NITs, Central Universities, State Universities, All)

### 8.2 Responsive Design

- Cards stack vertically on mobile
- Tables scroll horizontally on small screens
- Consistent with existing CareerGuide design system

### 8.3 Navigation

- Add "Special Admissions" link to navbar (between Colleges and Student Details in FastAPI, between Colleges and State Guide in static)
- URL: `/specialadmissions` (FastAPI), `/specialadmissions.html` (static)

## 9. Data Architecture

### 9.1 Data Model

```python
@dataclass
class AdmissionCriterion:
    name: str                    # e.g. "State Board Topper"
    description: str             # Brief explanation
    institutions: list[str]      # e.g. ["IITs", "NITs", "State Universities"]

@dataclass
class AdmissionCategory:
    id: str                      # e.g. "academic_merit"
    title: str                   # e.g. "Academic Merit & Topper Quotas"
    icon: str                    # Emoji icon
    criteria: list[AdmissionCriterion]
    certificates: list[str]      # Key documents needed
    sources: list[dict]          # [{name, url}]
```

### 9.2 Data File

- `src/careerguide/data/admission_data.py` — all admission categories as structured data
- Exported via `src/careerguide/data/__init__.py`
