# Student profile

This prd document to list out all the required information of the student to ensure 
it has enough information to anlayze and suggest the correct stream.

| Input | Description | Example |
|-------|-------------|---------|
| Name | Name of the student | Ravi Sharma |
| Standard | 10th, 12th | Class the student is currently studying in |
| Percentage | 10th or 12th marks percentage | Percentage obtained in the respective class, 12 % is option is student is studying in 10th standard |
| Interest | Refer docs/careerpaths-prd.md  | Single subject stream the student is most interested in (radio button — one selection only) |

Based on the interest generate the report only for that stream.
